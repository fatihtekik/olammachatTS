# Обновление системы для работы с новыми полями Excel

## Изменения в системе

### 1. Обновлены модели базы данных

Добавлены новые поля в модели `Match` и `MatchSet`:

**Match (backend/app/models/match.py):**
- `serve_efficiency_p1` - Эффективность подачи игрока 1 в матче (%)
- `receive_efficiency_p1` - Эффективность приёма игрока 1 в матче (%)
- `serve_efficiency_p2` - Эффективность подачи игрока 2 в матче (%)
- `receive_efficiency_p2` - Эффективность приёма игрока 2 в матче (%)
- `match_duration_formatted` - Время матча в формате "ЧЧ:ММ:СС"
- `timeouts_p1`, `timeouts_p2` - Таймауты игроков
- `yellow_cards_p1`, `yellow_cards_p2` - Жёлтые карточки
- `red_cards_p1`, `red_cards_p2` - Красные карточки
- `game_balance` - Баланс в игре

**MatchSet (backend/app/models/match.py):**
- `serve_efficiency_p1`, `receive_efficiency_p1` - Эффективность игрока 1 в сете
- `serve_efficiency_p2`, `receive_efficiency_p2` - Эффективность игрока 2 в сете
- `set_duration_formatted` - Время сета в формате "ММ:СС"
- `set_balance` - Баланс в сете

### 2. Обновлена схема ExcelMatchData

Добавлены поля для парсинга всех новых колонок Excel:
- Счета по сетам (до 5 сетов)
- Эффективность подачи/приёма для каждого игрока в матче и в каждом сете
- Время матча и каждого сета
- Таймауты и карточки
- Балансы

### 3. Обновлен парсинг Excel

Файл `backend/app/api/routes/match_analysis.py` теперь читает все новые колонки из Excel.

### 4. Обновлена функция создания матча

Функция `_create_match_from_excel` в `backend/app/services/match_analysis_service.py` теперь:
- Сохраняет эффективность игроков в матче
- Сохраняет эффективность игроков в каждом сете
- Сохраняет временные характеристики
- Сохраняет дисциплинарные данные
- Сохраняет балансы

## Формат Excel файла

Excel файл должен содержать следующие колонки:

### Обязательные колонки:
- Дата
- Игрок 1
- Игрок 2
- Счёт матча

### Новые колонки (опциональные):

**Счета по сетам:**
- Счет 1 сета Игрок 1, Счет 1 сета Игрок 2
- Счет 2 сета Игрок 1, Счет 2 сета Игрок 2
- Счет 3 сета Игрок 1, Счет 3 сета Игрок 2
- Счет 4 сета Игрок 1, Счет 4 сета Игрок 2
- Счет 5 сета Игрок 1, Счет 5 сета Игрок 2

**Эффективность в матче:**
- Эффективность подачи игрока 1 в матче
- Эффективность приёма игрока 1 в матче
- Эффективность подачи игрока 2 в матче
- Эффективность приёма игрока 2 в матче

**Эффективность в сетах (для каждого сета 1-5):**
- Эффективность подачи игрока 1 в 1 сете
- Эффективность приёма игрока 1 в 1 сете
- Эффективность подачи игрока 2 в 1 сете
- Эффективность приёма игрока 2 в 1 сете
- (и так далее для сетов 2-5)

**Временные характеристики:**
- Время матча
- Время 1 сета, Время 2 сета, ..., Время 5 сета

**Дисциплинарные действия:**
- Таймауты Игрок 1, Таймауты Игрок 2
- Жёлтые карточки Игрок 1, Жёлтые карточки Игрок 2
- Красные карточки Игрок 1, Красные карточки Игрок 2

**Балансы:**
- Балансы в игре
- Баланс в 1 сете, Баланс в 2 сете, ..., Баланс в 5 сете

## Инструкция по применению изменений

### Шаг 1: Применить миграцию базы данных

```powershell
cd backend
alembic upgrade head
```

Это создаст все новые поля в таблицах `match` и `matchset`.

### Шаг 2: Перезапустить backend

```powershell
cd backend
python main.py
```

или используйте ваш обычный способ запуска backend.

### Шаг 3: Загрузить новый Excel файл

Теперь вы можете загружать Excel файлы с новыми колонками через интерфейс приложения.
Система автоматически:
- Извлечёт все новые данные из Excel
- Сохранит эффективность игроков для каждого матча
- Сохранит эффективность игроков для каждого сета
- Сохранит временные характеристики
- Сохранит дисциплинарные данные
- Сохранит балансы

## Проверка работы

После применения изменений проверьте:

1. База данных содержит новые поля:
```sql
SELECT column_name FROM information_schema.columns 
WHERE table_name = 'match' 
AND column_name LIKE '%efficiency%';
```

2. Загрузите тестовый Excel файл с новыми колонками
3. Проверьте, что данные сохранились в БД

## Примечания

- Все новые поля опциональны (nullable=True)
- Если какие-то колонки отсутствуют в Excel, они будут NULL в БД
- Старые Excel файлы без новых колонок будут работать как прежде
- Эффективность хранится как целое число (проценты)

## Откат изменений

Если нужно откатить изменения:

```powershell
cd backend
alembic downgrade -1
```

Это удалит все новые поля из базы данных.
