# 🏓 Система анализа триггеров - Обновления

## 🚀 Что нового

### Новые типы триггеров
Добавлено 8 новых типов триггеров для более глубокого анализа проблем игроков:

1. **Поражения 0:3** - анализ разгромных поражений
2. **Выиграл 2 сета, проиграл 3-й** - проблемы с завершением матчей  
3. **Досрочный выход из финала** - анализ игры под давлением
4. **Вёл 1 сет и проиграл** - проблемы с удержанием преимущества
5. **Вёл 2 сета и проиграл** - критические психологические проблемы
6. **Психологические срывы** - комбинированный анализ ментальных проблем
7. **Неспособность к камбекам** - анализ способности отыгрываться
8. **Игра под давлением** - результаты в важных матчах

### Новый интерфейс анализа
- **Два режима**: Загрузка Excel + Анализ базы данных
- **Гибкие настройки**: Период, игроки, типы триггеров
- **Красивое отображение**: Цветовая индикация серьезности
- **Детальная информация**: Статистика и рекомендации

### Новые API эндпоинты
- `POST /analyze-database` - анализ матчей из БД
- `GET /triggers` - получение триггеров с фильтрацией
- `GET /players` - список игроков со статистикой
- `GET /trigger-types` - доступные типы триггеров

## 🧪 Как протестировать

### 1. Запуск сервера
```bash
cd backend
python main.py
```

### 2. Тестирование API
```bash
python test_triggers_api.py
```

### 3. Интерфейс
1. Откройте приложение в браузере
2. Перейдите в раздел "Анализ"
3. Выберите "Анализ базы данных"
4. Настройте параметры и запустите анализ

## 🎯 Примеры использования

### Анализ конкретного игрока
```javascript
POST /api/v1/match-analysis/analyze-database
{
  "period_start": "2024-01-01",
  "period_end": "2024-12-31",
  "player_ids": ["player_id"],
  "trigger_types": ["defeat_0_3", "led_2_sets_lost_match"]
}
```

### Поиск критических проблем
```javascript
GET /api/v1/match-analysis/triggers?severity_level=3&limit=20
```

### Получение топ игроков
```javascript
GET /api/v1/match-analysis/players?include_stats=true&limit=10
```

## 📈 Метрики анализа

Система анализирует:
- **Результаты матчей** - счёт по сетам
- **Этапы турниров** - финалы, полуфиналы
- **Временные паттерны** - серии поражений
- **Психологические факторы** - игра под давлением
- **Статистические аномалии** - отклонения от нормы
