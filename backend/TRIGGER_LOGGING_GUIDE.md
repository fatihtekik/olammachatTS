# Система Логирования Триггеров

## Описание

Система автоматически выводит в консоль детальную информацию о найденных триггерах во время анализа матчей.

## Формат Вывода

Для каждого найденного триггера выводится:

```
================================================================================
🎯 НАЙДЕН ТРИГГЕР: [ТИП_ТРИГГЕРА]
📊 [N] из [ОБЩЕЕ_КОЛИЧЕСТВО] - [название_триггера]
================================================================================
👤 Имя: [ФИО игрока]
🔍 Название триггера: [тип триггера]
📝 Описание: [подробное описание с статистикой]

🏃 Матчи где наблюдается триггер ([количество] матчей):
--------------------------------------------------------------------------------
  1. [ФИО_игрока] vs [ФИО_оппонента]
     Рейтинг 1: [рейтинг_игрока] | Рейтинг 2: [рейтинг_оппонента]
     Дата матча: [YYYY-MM-DD] | Начало матча: [HH:MM]
     Счёт: [счёт матча]
     Стадия: [стадия турнира, если есть]

  2. [следующий матч...]
================================================================================
```

## Типы Триггеров и Соответствующие Матчи

### 1. defeat_0_3
**Описание**: Поражения со счетом 0:3
**Показывает**: Только матчи с поражением 0:3

### 2. won_2_lost_3rd_set
**Описание**: Выиграл 2 сета, но проиграл 3-й решающий
**Показывает**: Матчи где игрок выиграл 2 сета, но проиграл матч

### 3. losing_streaks
**Описание**: Серии поражений подряд
**Показывает**: Последние поражения подряд (до 5 матчей)

### 4. losers_50_percent
**Описание**: Высокий процент поражений (>50%)
**Показывает**: Все поражения за анализируемый период

### 5. top_performers
**Описание**: Топ исполнители (позитивный триггер)
**Показывает**: Все победы за анализируемый период

### 6. time_performance
**Описание**: Проблемы в определенное время суток
**Показывает**: Матчи в проблемное время (утро/день/вечер/ночь)

### 7. early_final_exit_advanced
**Описание**: Досрочный выход из финала
**Показывает**: Финальные матчи с поражениями

### 8. post_holiday_problems
**Описание**: Проблемы после праздников
**Показывает**: Матчи в период после праздников

## Как Запустить Анализ

### Вариант 1: Через API
```bash
curl -X POST "http://localhost:8000/api/v1/match-analysis/analyze-database" \
  -H "Content-Type: application/json" \
  -d '{
    "period_start": "2025-06-01",
    "period_end": "2025-07-01",
    "trigger_types": ["defeat_0_3", "won_2_lost_3rd_set", "losing_streaks"]
  }'
```

### Вариант 2: Через тестовый скрипт
```bash
cd backend
python test_trigger_logging.py
```

### Вариант 3: Через веб-интерфейс
1. Откройте браузер
2. Перейдите на страницу анализа матчей
3. Выберите период и типы триггеров
4. Запустите анализ
5. Смотрите детали в консоли сервера

## Примечания

- Логи выводятся в консоль где запущен backend сервер
- Максимум показывается 10 матчей на триггер для читаемости
- Время начала матча отображается в формате HH:MM (например, 22:00)
- Если данные отсутствуют, отображается "н/д"
- Рейтинги берутся текущие (на момент анализа)
