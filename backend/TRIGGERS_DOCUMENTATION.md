# Система анализа триггеров - Документация

## Новые типы триггеров

Мы добавили 8 новых типов триггеров для более глубокого анализа проблем игроков:

### 1. Поражения 0:3 (`defeat_0_3`)
- **Описание**: Анализирует частоту поражений со счетом 0:3 
- **Критерий**: Больше 20% от всех поражений
- **Серьезность**: Высокая (2-3) 
- **Рекомендация**: Работа над психологической устойчивостью и стартовой готовностью

### 2. Выиграл 2 сета, проиграл 3-й (`won_2_lost_3rd_set`)
- **Описание**: Игрок выигрывает 2 сета, но проигрывает решающий 3-й
- **Критерий**: 30%+ от трёхсетовых матчей
- **Серьезность**: Высокая (2-3)
- **Рекомендация**: Проблемы с концентрацией в решающих сетах

### 3. Досрочный выход из финала (`early_final_exit_advanced`)
- **Описание**: Плохая игра в финальных матчах (проигрыш 0:3, 1:3)
- **Критерий**: 50%+ финалов - досрочные выходы
- **Серьезность**: Высокая (2-3)
- **Рекомендация**: Проблемы с игрой под давлением в решающих матчах

### 4. Вёл 1 сет и проиграл (`led_1_set_lost_match`)
- **Описание**: Игрок выигрывал хотя бы 1 сет, но проиграл матч
- **Критерий**: 40%+ от поражений
- **Серьезность**: Средняя (1-2)
- **Рекомендация**: Проблемы с удержанием преимущества

### 5. Вёл 2 сета и проиграл (`led_2_sets_lost_match`)
- **Описание**: Критический случай - игрок вёл 2:0, но проиграл 2:3
- **Критерий**: 2+ случая за период
- **Серьезность**: Критическая (2-3)
- **Рекомендация**: Критические проблемы с психологической устойчивостью

### 6. Психологические срывы (`psychological_breakdown`)
- **Описание**: Комбинированный анализ психологических проблем
- **Критерий**: 30%+ от матчей имеют признаки психологических проблем
- **Серьезность**: Высокая (2-3)
- **Рекомендация**: Требуется работа со спортивным психологом

### 7. Неспособность к камбекам (`comeback_inability`)
- **Описание**: Плохие результаты при попытках отыграться
- **Критерий**: 70%+ неудачных камбеков
- **Серьезность**: Средняя (1-2)
- **Рекомендация**: Работа над ментальной выносливостью и тактической гибкостью

### 8. Игра под давлением (`pressure_situations`)
- **Описание**: Плохие результаты в важных матчах (финалы, полуфиналы)
- **Критерий**: Меньше 30% побед в важных матчах
- **Серьезность**: Высокая (2-3)
- **Рекомендация**: Специальная подготовка к ответственным матчам

## Как использовать

### 1. Через интерфейс (Анализ > Анализ базы данных)
1. Выберите период анализа
2. Выберите игроков (или оставьте пустым для всех)
3. Выберите типы триггеров для анализа
4. Нажмите "Анализировать"

### 2. Через API
```javascript
POST /api/v1/match-analysis/analyze-database
{
  "period_start": "2024-01-01",
  "period_end": "2024-12-31", 
  "player_ids": ["player1", "player2"], // опционально
  "trigger_types": ["defeat_0_3", "won_2_lost_3rd_set"] // опционально
}
```

### 3. Получение всех триггеров
```javascript
GET /api/v1/match-analysis/triggers?severity_level=3&limit=50
```

## Уровни серьезности

- **1**: Низкая - требует внимания
- **2**: Средняя - требует активных действий  
- **3**: Высокая - критические проблемы, требуют немедленного вмешательства

## Метаданные триггеров

Каждый триггер содержит детальную информацию:
- Количественные показатели
- Процентные соотношения
- Рекомендации по устранению
- Дополнительная статистика

## Интеграция с существующими системами

Новые триггеры полностью совместимы с:
- Загрузкой Excel файлов
- Системой анализа чата с Ollama
- Существующими API эндпоинтами
- Базой данных матчей
