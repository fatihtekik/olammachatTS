# 🚀 Быстрый старт - Управление БД SportAI

## Главный интерфейс управления

Самый простой способ - использовать интерактивное меню:

```bash
cd backend
python database_tools/manage_database.py
```

Это откроет меню со всеми доступными операциями.

---

## Основные команды

### 1. 📊 Проверить состояние БД
```bash
python database_tools/check_database.py
```

**Что показывает:**
- Размер файла БД
- Список всех таблиц
- Количество записей в каждой таблице
- Статистика (активные триггеры, средний рейтинг, последний матч)
- Проверка целостности данных

---

### 2. 🆕 Создать новую БД

```bash
python database_tools/init_database.py
```

**Что делает:**
- Создаёт все таблицы согласно текущим моделям
- Добавляет дефолтные конфигурации триггеров
- Не удаляет существующую БД (для этого используйте clean_database.py)

---

### 3. 🗑️ Полная очистка БД

```bash
python database_tools/clean_database.py
```

⚠️ **ВНИМАНИЕ:** Удаляет ВСЕ данные из всех таблиц!

**Что удаляется:**
- Все матчи, сеты и триггеры
- Все игроки и их статистика
- История чатов
- Пользователи
- Праздники и конфигурации

Требует подтверждения (`YES`).

---

### 4. ♻️ Очистить только матчи

```bash
# Удалить ВСЕ матчи (сохранить игроков)
python database_tools/reset_matches.py

# Удалить матчи старше N дней
python database_tools/reset_matches.py 30
```

**Что делает:**
- Удаляет матчи, сеты и триггеры
- **Сохраняет** всех игроков и их рейтинги

---

### 5. 💾 Резервное копирование

```bash
# Создать бэкап
python database_tools/backup_database.py

# Восстановить из бэкапа
python database_tools/restore_database.py

# Восстановить конкретный файл
python database_tools/restore_database.py database_backups/ollamachat_backup_20250101_120000.db
```

**Автоматические бэкапы:**
- Перед восстановлением создаётся автоматический бэкап текущей БД
- Все бэкапы хранятся в `backend/database_backups/`
- Имя файла: `ollamachat_backup_YYYYMMDD_HHMMSS.db`

---

## 📋 Типичные сценарии использования

### Сценарий 1: Полная перезагрузка данных

```bash
# 1. Создать бэкап перед очисткой
python database_tools/backup_database.py

# 2. Очистить все данные
python database_tools/clean_database.py

# 3. Пересоздать таблицы
python database_tools/init_database.py

# 4. Загрузить новые данные через UI
```

---

### Сценарий 2: Очистка старых матчей

```bash
# Удалить матчи старше 90 дней
python database_tools/reset_matches.py 90

# Проверить результат
python database_tools/check_database.py
```

---

### Сценарий 3: Проверка перед важной операцией

```bash
# Проверить текущее состояние
python database_tools/check_database.py

# Создать бэкап
python database_tools/backup_database.py

# Выполнить операцию (например, загрузить Excel)
# ...

# Если что-то пошло не так, восстановить
python database_tools/restore_database.py
```

---

### Сценарий 4: Восстановление из бэкапа

```bash
# Показать список доступных бэкапов
python database_tools/restore_database.py

# Выбрать нужный и восстановить (ввести номер или путь)
```

---

## 🛑 Важные замечания

1. **Всегда делайте бэкап** перед опасными операциями
2. **clean_database.py** удаляет ВСЁ без возможности восстановления
3. **reset_matches.py** сохраняет игроков, но удаляет матчи
4. При восстановлении текущая БД автоматически бэкапится
5. Операции очистки требуют подтверждения (`YES` или `yes`)

## 💡 Подсказки

- Используйте `manage_database.py` если не знаете какую команду выполнить

- Бэкапы создаются быстро - не бойтесь их делать
- Для автоматизации используйте отдельные скрипты с параметрами
