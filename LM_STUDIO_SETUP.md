## 🔧 Как использовать LM Studio

### Шаг 1: Установите и запустите LM Studio

1. **Скачайте LM Studio**: https://lmstudio.ai/
2. **Установите приложение**
3. **Запустите LM Studio**

### Шаг 2: Скачайте и загрузите модель

1. Откройте вкладку **"🔍 Search"** (или Discover)
2. Найдите модель (рекомендуем):
   - `llama-3-8b` (быстрая, качественная)
   - `phi-3-mini` (очень легкая, 3.8 ГБ)
   - `mistral-7b` (хороший баланс)
3. Нажмите **Download**
4. Перейдите на вкладку **"💬 Chat"**
5. Выберите скачанную модель из списка
6. Нажмите **Load Model**

### Шаг 3: Запустите локальный сервер

1. Перейдите на вкладку **"⚡ Local Server"** (или Developer)
2. Убедитесь что порт установлен на **1234**
3. Нажмите **"Start Server"**
4. Вы увидите: ✅ **Server Running** (зелёная галочка)

### Шаг 4: Переключитесь на LM Studio в приложении

1. Откройте приложение olammachatTS
2. Нажмите на иконку **⚙️ Настройки AI** (шестеренка)
3. В секции **LM Studio**:
   - Нажмите кнопку **"Проверить"**
   - Должен появиться статус: ✅ **"Подключено"**
   - Вы увидите список доступных моделей
4. Нажмите кнопку **"Выбрать LM Studio"**
5. Готово! Теперь все запросы идут через LM Studio

## 🐛 Решение проблем

### Проблема: LM Studio показывает "Не подключено"

**Решение:**
1. Убедитесь что LM Studio запущен
2. Проверьте что сервер запущен (вкладка Local Server → Start Server)
3. Проверьте порт (должен быть 1234)
4. Перезапустите LM Studio

### Проблема: Модель не отвечает

**Решение:**
1. Убедитесь что модель загружена (Load Model в LM Studio)
2. Проверьте что модель активна (зелёная галочка)
3. Попробуйте отправить сообщение в самом LM Studio для проверки
4. Проверьте логи в консоли браузера (F12)

### Проблема: Slow/тормозит

**Решение:**
1. Используйте меньшую модель (phi-3-mini вместо llama-70b)
2. В LM Studio снизьте Context Length
3. Уменьшите Max Tokens
4. Закройте другие приложения

### Проблема: AI-анализ не работает

**Решение:**
1. Проверьте логи backend в терминале
2. Убедитесь что провайдер выбран правильно
3. Попробуйте переключиться на Ollama для теста
4. Проверьте что модель загружена в LM Studio
