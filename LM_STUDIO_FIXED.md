## 🚀 Как запустить:

### 1. Запустите LM Studio
```
1. Откройте LM Studio
2. Загрузите модель (Load model)
3. Запустите сервер:
   - Вкладка "Local Server"
   - Нажмите "Start Server"
   - Проверьте порт: 1234
```

### 2. Проверьте что LM Studio работает
```powershell
cd backend
python test_lmstudio_response.py
```

**Ожидаемый результат:**
```
✅ Статус: 200
✅ Валидный JSON
✅ delta содержит: content или reasoning
```

### 3. Запустите backend
```powershell
cd backend
python main.py
```

### 4. Запустите анализ
```
http://localhost:3000
Загрузите Excel → Анализировать
```

**Смотрите логи в терминале backend!**
