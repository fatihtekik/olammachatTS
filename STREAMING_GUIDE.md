# 🌊 Руководство по потоковой передаче (Streaming)

## Что это такое?

Потоковая передача (streaming) - это режим работы, при котором ответ от AI модели появляется постепенно, слово за словом, а не весь сразу после полной генерации. Это делает взаимодействие более естественным и отзывчивым.

## Как это работает?

### Включение/Выключение

1. Откройте **Настройки AI Провайдера** (иконка шестеренки ⚙️)
2. В разделе **"Настройки общения с моделью"** найдите переключатель **"Потоковая передача ответов (Streaming)"**
3. Включите/выключите переключатель по вашему желанию
4. Настройка сохраняется автоматически в localStorage

### Режимы работы

#### 🌊 Потоковый режим (По умолчанию - ВКЛЮЧЕН)
- ✅ Ответы появляются постепенно, слово за словом
- ✅ Вы видите прогресс генерации в реальном времени
- ✅ Более быстрая реакция интерфейса
- ✅ Приятнее для пользователя

#### 📦 Обычный режим (ВЫКЛЮЧЕН)
- ⏱️ Ответ появляется целиком после завершения генерации
- ⏱️ Нужно ждать полной генерации
- ✅ Меньше нагрузка на соединение
- ✅ Проще для отладки

## Технические детали

### Фронтенд

**Файлы:**
- `src/components/AIProviderSettings.tsx` - UI для переключателя стриминга
- `src/components/AIProviderSettings.css` - Стили для toggle переключателя
- `src/services/ollamaBackendApi.ts` - Функция `sendMessageStreaming()` для работы с потоком
- `src/App.tsx` - Обработка стриминга в `handleSubmit()`

**Формат данных:**
```typescript
// NDJSON (newline-delimited JSON)
{"content": "Hello"}\n
{"content": " world"}\n
{"content": "!"}\n
```

### Бэкенд

**Файлы:**
- `backend/app/api/routes/ollama.py` - Эндпоинты с поддержкой `stream` параметра
- `backend/app/services/lm_studio_service.py` - Функция `stream_message_to_lm_studio()`

**API параметры:**
```json
{
  "model": "phi3",
  "messages": [...],
  "stream": true  // Включить стриминг
}
```

### Поддержка провайдеров

| Провайдер | Стриминг | Формат ответа |
|-----------|----------|---------------|
| **Ollama** | ✅ Да | NDJSON: `{"content": "text"}` |
| **LM Studio** | ✅ Да | SSE (Server-Sent Events) с OpenAI форматом |

## Устранение проблем

### Стриминг не работает

1. **Проверьте настройку** - Убедитесь, что стриминг включен в настройках
2. **Проверьте консоль браузера** - Смотрите логи ошибок
3. **Проверьте бэкенд** - Убедитесь, что параметр `stream: true` передается
4. **Проверьте провайдер** - Ollama/LM Studio должны быть запущены

### Ответ появляется рывками

- Это нормально для медленных моделей
- Зависит от скорости генерации модели
- Зависит от мощности вашего компьютера

### Ошибки соединения

- Проверьте, что Ollama или LM Studio запущены
- Проверьте, что бэкенд работает
- Попробуйте отключить стриминг временно

## Сохранение настроек

Настройка стриминга сохраняется в `localStorage`:
```javascript
localStorage.setItem('streamingEnabled', 'true'); // или 'false'
```

По умолчанию стриминг **ВКЛЮЧЕН** для лучшего пользовательского опыта.
